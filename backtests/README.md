# Backtests

Every feature in Turblance Trader ships with a validation report here.

## Evidence standard (draft — finalized in Phase 1 spec)

- Clearly stated hypothesis and success metric
- In-sample vs out-of-sample split (no peeking)
- Transaction costs and slippage modeled
- Sample sizes and confidence reported honestly
- Limitations section — what the test does *not* prove

A signal without a passing report is labeled experimental and never presented
as reliable.
